# CAD and Mechanical Integration

The TARS project uses an existing CAD model as a mechanical baseline. The original CAD geometry was not authored by me.

My contribution is limited to modifications and integration work performed to support the TARS project, such as component fitment, display alignment, mounting geometry, packaging, and integration of selected hardware.

Any CAD files added to this folder should retain appropriate attribution and licensing information for the original source when available. Modified files will be identified as derivative or adapted work rather than presented as original CAD design.
