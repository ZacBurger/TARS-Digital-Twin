# SysML Diagrams

This folder will contain exported diagrams from the TARS Cameo Systems Modeler project.

Planned exports include:

- Block Definition Diagram (BDD)
- Internal Block Diagram (IBD)
- Activity Diagram
- State Machine Diagram
- Sequence Diagram
- Parametric Diagram
- Requirements / verification views

The exported diagrams are intended to make the engineering work viewable directly in GitHub without requiring Cameo.
