# SysML Diagrams

This folder contains exported diagrams from the TARS Cameo Systems Modeler project so the engineering work can be reviewed directly in GitHub without requiring Cameo.

## Current Exports

### BDD-LA-01 — TARS Logical Architecture

This Block Definition Diagram shows the top-level TARS system decomposition and major subsystem relationships, including mobility and articulation, user interface, sensing and safety, battery/power, data logging/digital twin interface, and control/compute.

![TARS Logical Architecture](./BDD-LA-01%20TARS%20Logical%20Architecture.jpg)

[Open full-size diagram](./BDD-LA-01%20TARS%20Logical%20Architecture.jpg)

### STM-01 — TARS Operational States

This State Machine Diagram captures the primary operating states and transitions used to model TARS behavior, including controller pairing, digital twin synchronization, SafeStop, maintenance, and fault-response logic.

![TARS Operational States](./STM-01%20TARS%20Operational%20States.jpg)

[Open full-size diagram](./STM-01%20TARS%20Operational%20States.jpg)

### SEQ-01 — Execute Demonstration Mission

This Sequence Diagram shows time-ordered interactions across the demonstration mission scenario, making system responsibilities, message flow, and coordination between participating elements easier to review.

![Execute Demonstration Mission](./SEQ-01%20Execute%20Demonstration%20Mission.jpg)

[Open full-size diagram](./SEQ-01%20Execute%20Demonstration%20Mission.jpg)

### PAR-01 — Mission Energy Analysis

This Parametric Diagram captures the relationships among battery voltage, battery capacity, conversion efficiency, average power, mission duration, usable energy, required energy, and energy margin. It provides an analytical view for assessing whether the power architecture can support the planned mission duration.

![Mission Energy Analysis](./PAR-01%20Mission%20Energy%20Analysis.jpg)

[Open full-size diagram](./PAR-01%20Mission%20Energy%20Analysis.jpg)

### VER-01 — TARS Verification Plan

This verification view documents planned verification activities and their relationship to system requirements, demonstrating how the model supports requirements-to-test traceability and verification planning.

![TARS Verification Plan](./VER-01%20TARS%20Verification%20Plan.jpg)
