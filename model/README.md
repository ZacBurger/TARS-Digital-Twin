# Native Model

This folder is reserved for the current TARS Cameo Systems Modeler source model.

Planned file:

- `TARS_Current_Model.mdzip`

The `.mdzip` file is the native project model and requires compatible Cameo / MagicDraw software to open. Exported diagrams and documentation will be maintained elsewhere in the repository for browser-based review.

Because the project is under active development, the model version may change frequently.
