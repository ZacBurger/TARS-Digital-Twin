# Native Model

This folder contains the current TARS Cameo Systems Modeler source model.

Current file:

- [`TARS_SysML_Master.mdzip`](./TARS_SysML_Master.mdzip)

The `.mdzip` file is the native project model and requires compatible Cameo / MagicDraw software to open. Exported diagrams and documentation are maintained elsewhere in the repository for browser-based review.

Because the project is under active development, the model will continue to evolve as the architecture, simulation, verification, and physical design mature.
